# Context

## Current Focus

The current focus of the Mov2mov project is to enhance video processing capabilities by:

- Refactoring the current structure to be more feature-first, separating UI and logic for better maintainability.
- Adding a feature to allow users to overlay elements like watermarks on generated videos.
- Revamping the movie editor feature to improve usability, allowing selective frame editing instead of applying changes to every frame.
- Adding an API for automation and integration with other systems.

## Recent Changes

- Added audio layer integration for video output.
- Improved logging functionality.
- Updated the README with new information.
- Introduced video editing features, including customizable keyframes and backtracking keyframe tags.
- Switched video synthesis from `ffmpeg` to `imageio`.

## Next Steps

- Complete the refactoring to adopt a feature-first structure.
- Implement the overlay feature for adding watermarks or other elements to videos.
- Revamp the movie editor for better user experience.
- Develop and integrate an API for automation.
- Explore adding more audio filters to enhance the audio layer functionality.
